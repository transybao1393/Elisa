# Elisa Brand Kit

Style 2h · character P2 Shade.

- 01-brand: principles, voice, mark usage
- 02-color: colors.json, colors.css (dark, light, character), palette.png
- 03-type: Silkscreen + Chivo Mono, type scale
- 04-layout: window spacing, alignment diagram, character grid, companion dock
- 05-character: Shade, 24 states (12 core + 8 work actions + 4 care): SVG 200/24, PNG 512, sprite sheet, motion JSON, renderer JS; alt Tanuki
- 06-icons: app icon, menu bar, UI icons (16/20)
- 07-motion: states, durations, easing, event → state mapping
- 08-source: live design files. Open "Elisa Prototype.dc.html" in a browser with the folder intact (fonts load from Google Fonts). "Elisa Shade Reel.dc.html" plays the reel.
