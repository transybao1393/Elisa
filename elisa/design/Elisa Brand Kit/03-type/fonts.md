# Fonts

Both are free under the SIL Open Font License.

- Silkscreen 400/700: https://fonts.google.com/specimen/Silkscreen
- Chivo Mono 400/500/600: https://fonts.google.com/specimen/Chivo+Mono

```html
<link href="https://fonts.googleapis.com/css2?family=Chivo+Mono:wght@400;500;600&family=Silkscreen:wght@400;700&display=swap" rel="stylesheet">
```

For the macOS app, download the TTFs and bundle them (ATSApplicationFontsPath in Info.plist).

| Role | Font | Size / line |
|---|---|---|
| Body | Chivo Mono 400 | 13 / 21 |
| User turn | Chivo Mono 600 | 13 / 21 |
| Code, paths | Chivo Mono 400 | 12.5 / 21 |
| Status bar | Chivo Mono 400 | 12 / 22 |
| Metadata | Chivo Mono 400 | 11.5 / 17 |
| Small, rail | Chivo Mono 400 | 11 / 16 |
| App name | Silkscreen 400 | 11, uppercase |
| Bubble verb | Silkscreen 400 | 10, uppercase, +.06em |
| Permission title | Chivo Mono 600 | 15 / 22 |
| Prompt caret | Chivo Mono | 14 / 22, accent |
