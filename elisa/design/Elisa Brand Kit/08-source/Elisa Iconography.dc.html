Iconography

App icon, menu bar glyph, UI icon set and spec sheet for Elisa. Every asset on this page is an SVG file in the project, named elisa-icon-<name>-<size>.svg.

01

App icon — concepts

ASELECTED → REFINED
Continuous “e” + cursor
One line draws the letter; a coral block cursor follows it. Ownable as a letterform and reads at every size. Refined below: the cursor moves into the crossbar.
B
Node inside a soft enclosure
A coral node held inside a soft square: local, contained, private. Drawn as a node rather than a spark, since a coral spark on a dark tile sits too close to existing AI-assistant marks. Generic at 16 px.
C
Prompt chevron + dot
A “›” prompt with a coral dot: command line and conversation in one mark. Strongest at 16 px, but the chevron is shared by most terminal apps.
02

App icon — refined

An off-white bowl drawn as one stroke; the crossbar is the coral cursor. A small gap on the left keeps the bar reading as a cursor, not just a letter part.
1024–256Master. 64 u stroke, top sheen, hairline inner edge, drop shadow.
128Stroke 70 u so the bowl holds 9 px.
64Stroke 78 u, crossbar gap widened to 1.5 px, no hairline.
32Redrawn on a 32 grid. 2.4 px stroke, no sheen, 0.4 px shadow.
16Redrawn on a 16 grid. 1.5 px stroke, crossbar joins the bowl, flat tile.

64 u grid (16 × 16 modules)
Bowl centre 512, 516 · radius 196 · stroke 64
Crossbar at y 500, 16 u gap to the bowl
Terminal cut at 42° below horizontal
Shadow y 12, blur 14, 35 % black. Gradient #2A2A33 → #1E1E24, top to bottom.

Clear space
