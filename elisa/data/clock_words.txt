# The day and the part of the day in the user's language, for a question about the time or the date
# (`situation::clock_words`). Elisa's own clock line is in English ("22:10 Tuesday evening"); a small model put it
# into Vietnamese as "thứ hai chiều" (Monday afternoon). With these words in the turn the model copies them, and a
# reply that names another day or part next to the time is put right (`situation::ReplyFacts`).
#
# One section per language. Every value is "written with accents | written without accents" (a message without
# accents gets the second form). Keys:
#   asks       words that make a message a question about the time or the date in this language
#   days       Sunday … Saturday
#   day asks   the words asking which day it is: a reply that repeats one in place of the day gets today's name
#   morning, noon, afternoon, evening, late night   the parts of the day (`situation::part_of_day`)
#   hours      which hours each part holds, as "part from-to" (a range past midnight wraps: "late night 23-4") or
#              "part hour"; the first range holding an hour names it, a later one holding it too is also right
#              there (a reply saying it is left as it is). A language with none uses English's.
#   greet      what may come before a part of the day in a greeting ("good" morning, "chào buổi" sáng): a message
#              opening that way, or with the part alone ("morning!"), greets for that part (`situation::day_note`);
#              nothing else before it ("I sang.", "this morning I ran") is a greeting
#   time asks  the asks among them that want the clock time (a wording not here is read by meaning from the
#              examples of data/time_asks.txt): a reply with no time in it, or with junk around it, is Elisa's own
#              `answer`, and a time in it that is not the real one is put right (`situation::ReplyFacts`)
#   say        that time in this language: {time}
#   answer     Elisa's own whole answer to a time ask, when the reply has no clock time or wraps it in words that
#              answer nothing (a denial, garbled text, talk about a word of the message): {time} {day} {part} and
#              the date {d} {m} {y}, from her own clock line (`situation::ReplyFacts`)
#   place answer   the same for a place asked ("what time is it in Paris?"): {place} and its {zone} (the offset
#              and label of her "Time in … now" line)
#   hour words, minute words   what follows the hour and the minutes of a time said in words ("hai giờ hai chín
#              phút", "two o'clock"; the numbers from data/number_words.txt): such a time is checked like "02:29"
#   line       the words given to the model: {time} {part} {day} {d} {m} {y}; none for English (Elisa's clock
#              line is English already): its words only put a reply right
#   now week   words that say where in the week it is now ("a great way to start the week", "chúc cuối tuần vui"), each
#              group "wording | wording: the days it fits" (0 Sunday … 6 Saturday), ";" between groups: on any other
#              day, with no day or week word in the user's message, the sentence saying it goes
#              (`situation::without_wrong_week_words`)
# Fix a missed wording by adding it here, not in code.
