# Wordings with which a reply claims a tool's action or result (`reply_check::tool_claims`): that it read a file and
# what it holds, that it saved or created a file, or that it changed one. On a turn where no such tool ran (and no
# earlier read, write or edit of that file backs the sentence), the claim is false: the sentence goes and Elisa's own
# line says what did and did not happen (`repl/docs.rs` `false_claim_line`, lines in `data/no_answer_lines.txt`).
# A saved-file or change claim the older checks find themselves (`route::claims_file_saved`,
# `reply_check::is_done_claim_for`) stays theirs: they ask the model once more first.
# One key per line, "key: wording | wording | …", in an [en] and a [vi] section, with and without accents; matched as
# whole words, in a sentence that names a file (or on a turn whose message names one). Fix a missed wording here,
# not in code.
#   read:  the reply says it read a file or tells its content ("I read notes.txt", "the file contains", "đọc file …,
#          tôi thấy")
#   write: it says a file was saved or created ("saved to hello.txt", "đã ghi lại … vào file hello.txt")
#   edit:  it says a file was changed ("changed 'buy milk' to 'buy bread'", "đã đổi … thành …")
#   run:   it reports a command's run or output ("It printed hello-elisa again.", "đã chạy lại, kết quả là …"); needs
#          no file in the sentence; false on a turn that ran nothing where the message asks for a thing to be done
#          ("again"), not where it asks about an earlier run ("what did it print?")
#   run_result: a result told with no run in its words ("the result is …", "kết quả là …"): a run claimed only where
#          the message is about a run (a `run_asks` word: "run", "lệnh"); to "tính giúp mình 25% của 480" it is the answer
#   run_asks: words of a message about running a command or its output
#   not:   a word that makes the sentence no claim (a denial or a failure: "not saved", "chưa", "lỗi")
#   hedge: a word that makes it a plan, an offer or a condition, not a report ("I will save", "sẽ", "nếu bạn muốn"),
#          or a fix in a release rather than here ("was fixed in 2.20.0", "trong phiên bản")
#   file:  the words that stand for a file when none is named ("the file", "tệp")
