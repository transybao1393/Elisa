# Elisa's own answer to her security checks (`repl/turn.rs` `deps_block`, `check_block`): the lines are built only
# from the check's result, so the answer is the same on every model. One entry per line as "key.lang = text"; `lang` is en or vi (the
# reply follows the user's language). Fields in braces are filled in by Elisa. Change the wording here, not in code.
#   package:      one line per package with advisories ({name} {version} {count} {worst} {fix})
#   package_one:  the same for a package with one advisory
#   advisory:     one line per advisory under its package ({id} {level} {fixed} {title})
#   no_level:     the level shown when the check gives none
#   no_fix:       the fixed versions shown when the check gives none
#   more:         the line after a list cut short ({count} advisories not shown)
#   todo:         the label before the model's short note on what to do
#   note:         Elisa's note to the model with the verified list ({block}); never shown to the user
#   secrets_head / secrets_head_one: the first line of a secrets scan's answer ({hits} {files} {scanned})
#   secret:       one line per finding, the secret masked as the check gives it ({file} {line} {rule} {masked})
#   secrets_more: the line for findings the check did not list ({count})
#   no_secrets:   a scan that found none ({scanned})
#   binary_head:  the first line of a binary check's answer, its findings under it as the check gives them ({file} {bytes})
#   jwt_head:     the first line of a token check's answer, the decoded parts under it as the check gives them
#   check_note:   Elisa's note to the model for these checks ({block}); never shown to the user
