# Words for an amount or a unit beside a number that make it a value (`repl/turn.rs` `live_figures`): "139 triệu",
# "84,5 triệu đồng", "2.3 million", "1.200 USD", "5 nghìn", "3 tỷ", "403.547 người", "$950", "28°C", "0,00%". Grouped
# by the kind of value the unit gives (`figure_kind`): a count of people, money, degrees, a share, a length, a mass, a
# speed, an area. One section per kind, "[kind]", with these keys (every list is "a | b | c"):
#   unit:  the unit words and signs of the kind. A sign ("$", "°", "%") counts right beside the number with no space
#          ("$950", "28°C", "5%"); a word of two letters or more counts written onto the number too ("21oC", "5km",
#          "139tr"); a single letter only after a space ("24k" is gold's purity, "5 k" an amount). Units may follow
#          one another, with a "/" between ("đồng/lượng", "USD/ounce", "km/h"): the first after the multipliers gives
#          the kind.
#   ask:   the words of an ask that take this kind ("population" a count, "price" money, "nhiệt độ" degrees): the
#          figure given for the ask must be of a kind it takes, or plain (`live_sentence`); they also make the ask one
#          for a figure from the web (`figure_ask`).
#   not:   longer wordings an `ask` word does not count inside ("đánh giá" is a review, not a price).
# [multiplier] holds the words that scale a number ("139 triệu", "2.3 million"): the unit after one gives the kind
# ("2.3 million people" is a count); none leaves the number plain. A plain number (one with a separator, "394,324", or
# a multiplier alone, "139 triệu") can be any kind's value; a figure of a kind the ask does not take is never the asked
# figure ("0,00% dân số thế giới" is a share, not the population; "$11,000 to climb" is money, not Everest's height).
# A kind headed "[share] only when asked" is taken only by an ask naming it: an ask naming no kind takes every other.
# [range] holds the frames of two figures that give a range, not one value ("wavered between about 30,000 and
# 80,000", "từ 40.000 đến 60.000 người"): "{}" stands for a figure, one word may come before it ("about", "khoảng").
# A sentence of such a range comes after one giving a single value.

# range frame here, not in code.
