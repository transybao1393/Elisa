# Words for a reply's sentences about its own instructions or about who gave a file's content
# (`reply_check::without_meta_narration`, `reply_check::credited_to_source`; the file tools clean content to save with
# the same rule). One key per line, "key: wording | wording | …", in an [en] and a [vi] section, with and without
# accents. Fix a missed wording here, not in code.
#   narrate:  a sentence holding one tells the model's instructions instead of answering ("the user wants me to"): it goes
#   subject:  who a sentence credits content to, at its start ("the user")
#   again:    the same, said again later in the reply once one sentence credited the user ("they")
#   filler:   words that may stand between the subject and the verb ("also", "has")
#   gave:     verbs that credit the content to that subject ("provided", "shared", "has")
#   gave_not: words after such a verb that make it no credit ("has been", "has to")
#   self_before: words before a name that claim it as the speaker's own ("I'm", "Tôi là"): with a name of the
#                user's facts, not the assistant's, the sentence goes
#   self_after:  words after a name that do the same ("Bo here")
#   assistant_words: words for an assistant or a model ("assistant", "trợ lý"): after a `self_before` wording, the
#             sentence is a self-introduction; beside an answer to anything else it goes (`reply_check::self_intro`)
#   past_aux:   helping words of a past action ("has", "đã"): after an assistant subject they count only with an
#             action after them ("Elisa đã chạy", "Elisa has read"; "Elisa has three tools", "Trợ lý đã sẵn sàng" stay)
#   past_verbs: English irregular pasts ("ran", "wrote"); with an "-ed" word, or a tool action word of
#             `data/tool_claims.txt`, they are the action (`reply_check::tells_own_action`): such a sentence tells the
#             assistant's own action back in the third person, which is retelling
#   retell:   words of a sentence that tells the conversation back instead of answering ("your question is", "Elisa
#             answered", "câu hỏi của bạn là"): beside an answer it goes; a reply of only such sentences answers
#             nothing (`reply_check::without_retelling`, `retells_only`)
#   to_you:   "said of the user > said to them" pairs: a reply that speaks of the user in the third person ("The user
#             should consider updating") is said to them ("You should consider updating") (`reply_check::said_to_user`)
#   source_lead: a lead-in that credits what follows to the model's or a tool's output ("the model output showed
#             that", "based on the provided information,"): it is left out and the rest kept
#             (`reply_check::without_source_lead`)
#   blame:    a sentence holding one blames the user's message ("there seems to be a mistake in your message"): beside
#             an answer it goes (`reply_check::without_false_blame`)
#   to_me:    "said to the user > said by the user" pairs: a reply's clause that tells the user a fact of theirs ("your
#             name is Jonathan") read as the user would state it ("my name is Jonathan"), so the same wordings as the
#             user's own facts find its value (`reply_check::without_unbacked_user_facts`)
#   you_gave: words that say the user gave something ("you provided", "you mentioned"): with an `earlier` word in the
#             same sentence, it claims the user gave the thing named next to it ("the timezone you provided earlier")
#             in an earlier message; when the user's earlier words and facts never named that thing, the sentence goes
#             (`reply_check::without_unbacked_user_facts`)
#   earlier:  words that place the giving in the past ("earlier", "previously", "trước đó")
#   about_words: words of a sentence that describes the user's message itself, its words or pronouns ("'I' and 'my'
#             are used in your messages", "is used to refer to the user") where nothing about words was asked: a reply
#             of only such sentences answers nothing (`reply_check::about_message_words`: asked once more, then Elisa's
#             plain line); beside an answer they go (`reply_check::without_message_meta`)
#   word_asks: words of an ask about words, meaning or grammar ("what does 'my' mean here?"): such a reply answers it
#   (a sentence that opens with a quoted person word and defines it, "\"I\" is …", counts as `about_words` too:
#   `reply_check::defines_person_word`, with the person words of `data/person_words.txt`)
